== Frequently Asked Questions ==
= Where do I report security bugs found in this plugin? =

Please report security bugs found in the source code of the Hotel + Bed and Breakfast Booking Calendar Theme | Bellevue WordPress theme plugin through the [Patchstack Vulnerability Disclosure  Program](https://patchstack.com/database/vdp/3f5ee92e-8241-413f-90d7-09a25155269e). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.

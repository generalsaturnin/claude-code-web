# Thème enfant « La Crochardière » (parent : GeneratePress)

Thème enfant pour le site vitrine. Toutes les personnalisations vivent ici ;
on ne modifie jamais GeneratePress (le parent), qui reste à jour.

## Installation
1. Installer et activer **GeneratePress** (Apparence → Thèmes → Ajouter → « GeneratePress »).
2. Installer **GenerateBlocks** (Extensions → Ajouter → « GenerateBlocks »).
3. Déposer ce dossier dans `wp-content/themes/lacrochardiere/`.
4. Apparence → Thèmes → activer **La Crochardière**.

## Personnaliser
- **CSS** → `style.css` (chargé après GeneratePress).
- **PHP / hooks** → `functions.php` (voir les hooks GeneratePress).
- Réglages visuels globaux → Apparence → Customizer.
